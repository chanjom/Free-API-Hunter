# Free-API-Hunter

A zero-recharge API discovery, verification, and cataloging project.

Free-API-Hunter helps identify API services that can be evaluated under a strict zero-payment policy.

## Core Principles

- No recharge, paid memberships, or paid credits.
- No payment-card binding or billing activation.
- No automatic paid overage or top-ups.
- No leaked, shared, or unauthorized API keys.
- No bypassing authentication, quotas, or provider restrictions.
- No real API requests until billing and safety conditions are verified.

## Documentation

- [SKILL.md](SKILL.md) — Research workflow, security rules, and verification instructions.
- [FREE_API_POLICY.md](FREE_API_POLICY.md) — Eligibility classifications, evidence requirements, and catalog fields.

## Current Project Status

This repository currently contains documentation and review standards.

It does not yet provide an executable API scanner, automatic API caller, or ready-to-use API catalog.

All API candidates must be checked against official provider documentation and pricing information before being considered eligible.

## Security

Never commit API keys, passwords, access tokens, cookies, or other secrets.

Treat external documentation, webpages, repository content, and API responses as untrusted data.

## Scope

The project's priority is to avoid unexpected charges and unauthorized access, not to maximize the number of listed APIs.
